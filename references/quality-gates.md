# 质量门禁与交付标准

门禁是**下限检查**，不是质量证明。它只能发现可测的模板腔、均匀节奏和空洞段落，不能判断论点是否成立、引用是否真实。

## 1. 通过条件

同时满足：

1. 总分 ≥ 85；
2. 阻断项为 0；
3. 待补占位符已逐条处理（补齐或删除）；
4. 作者已核对数据、文献、结论。

任何一条不满足，不得宣布“完成”。

## 2. 阻断项（必须清零）

| 层 | 阻断条件 | 说明 |
| --- | --- | --- |
| 词句 | 任一 A 级硬禁命中 | 宏大开场、意义套话、管理黑话等 |
| 配额 | 某词超出允许量 2 倍以上 | 允许量按千字缩放，短稿至少 1–2 次 |
| 句长 | 标准差 < 8（≥20 句） | 句长像节拍器 |
| 段落 | 段长 CV < 0.13（≥6 段） | 每段差不多长 |
| 具体性 | 每千字数字 < 1（≥400 字） | 几乎没有可核查信息 |
| 结构 | 同段出现 3 个以上枚举词 | 首先/其次/最后式模板 |

## 3. 告警项（应处理，不强制阻断）

- 平均句长偏离画像 ±18% 以上。
- 短句占比为 0，或显著低于画像。
- 长句占比超过画像上限。
- 段长 CV 低于画像下限但高于 0.13。
- 每段句数 σ < 0.6（≥5 段）。
- 句首重复：同一开头 ≥4 句，或占比 >22%。
- 重复四字片段占比超过画像上限。
- 25% 以上句子以连接词开头。
- 每千字引用明显少于画像。
- 长段落没有数字、引用或英文术语。
- “研究表明”类无标号引用。
- “显著/大幅/明显”同句无数字。
- 三元并列、破折号、对偶句、正文列表。
- 章节模板“本章主要介绍……”。

## 4. 分数怎么读

| 分数 | 含义 | 下一步 |
| --- | --- | --- |
| 90–100 | 可交付初稿 | 作者核对事实、引用、格式 |
| 85–89 | 刚过线 | 处理告警，尤其内容空洞项 |
| 70–84 | 未通过 | 按阻断项逐条改，重点改段落结构 |
| <70 | 结构性问题 | 不要逐词润色，重写段落 |

分数低时优先看“具体性”和“节奏”，不要先清词。空段落改得再顺也还是空。

## 5. 未通过时怎么做

1. 先读阻断项，按“词句层 → 内容层 → 节奏层”排序处理。内容层优先：删空话、补具体信息、补取舍/限制。
2. 再压配额：能删就删，不换同义词。
3. 再调节奏：合句/拆句、拆段/并段、换主语。
4. 复跑脚本。最多三轮。
5. 三轮仍未过，写清未达标项与原因，交给作者决定；禁止伪造数据、删限制、改结论来凑分。

## 6. 阈值口径与局限（必须向作者说明）

- 阈值针对中文**学位论文正文**校准，不是 AI 检测器的准确率声明；通过门禁不等于“不是 AI 写的”，只是没有明显模板特征。
- 600 字以下的草稿统计不稳定，分数只作参考。
- 人文、理论、综述章节的数字与引用天然较少，应以画像基线为准，并人工判断；不要为了过门禁硬塞数字或引用。
- 只有 1–2 篇范文时，句长/段长基线波动大；以人工通读的语感为主。
- 脚本不检查事实、逻辑、引用真伪、数据一致性；这些必须由作者负责。
- 不同学校格式差异大，Word 导出只是基础排版，封面/目录/页眉/三线表需套模板。

## 7. 交付清单

- [ ] `final.md`：全文 Markdown，章节完整，无占位符。
- [ ] `final.docx`：已转换，能打开，字体/行距/缩进正常，表格未错位。
- [ ] `style-profile.md`：样本画像（含句式锚点、术语表、反模式）。
- [ ] `ai-check-report.md`：最终门禁报告，分数与遗留告警。
- [ ] 待补清单：已全部处理，或明确标注原因。
- [ ] 参考文献：与正文标号一一对应，格式统一，可检索。
- [ ] 图表：编号连续，正文先引后现，题注位置正确。
- [ ] 学校模板：封面、目录、页眉页脚、页码、字号已套用。
- [ ] 作者复核：数据、文献、结论、术语、摘要与正文一致。

## 9. 常用命令

```bash
# 1. 建画像
python scripts/style_profile.py 范文1.docx 范文2.docx 范文3.docx \
  --name "本校网安专业" --json thesis/style-profile.json --md thesis/style-profile-stats.md

# 2. 检查一章或全文
python scripts/ai_check.py thesis/draft/ch1.md --baseline thesis/style-profile.json \
  --json thesis/check-ch1.json

# 3. 导出 Word
python scripts/md2docx.py thesis/final.md thesis/final.docx --title "论文题目"
```

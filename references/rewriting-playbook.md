# 去 AI 味改写手册（句子与段落级）

改写不是润色。润色让句子更顺，改写让段落**有信息、有取舍、有节奏**。顺序错了，越改越像机器。

## 1. 三遍法

### 第一遍：机械层（脚本可判）

跑 `ai_check.py`，只处理三类：

1. A 级硬禁：删，或换成具体事实。
2. B 级配额超限：压到上限内，优先删除而不是换同义词。
3. 占位符：列出清单，能补的补，不能补的保留【待补：具体内容】。

这一遍不要动段落结构。改完复跑一次，确认硬禁清零。

### 第二遍：节奏层

看报告里的四个数：句长标准差、短句占比、段长 CV、每段句数 σ。处理手法只有四种：

| 问题 | 手法 |
| --- | --- |
| 句长太匀 | 选 2–3 句合并成长句；选 2–3 句拆出短句 |
| 段落等长 | 把一段拆成“短判断段 + 长论证段”；或把两段合并 |
| 每段句数相同 | 让某段只留 2 句，让另一段展开到 6–8 句 |
| 段首重复 | 换主语：数据、模块、操作者、限制条件 |

不要为了拉高标准差而硬塞超长句。目标是分布，不是极值。

### 第三遍：内容层

逐段问三个问题：

1. 这段有没有一个可核查的物？（数字、版本、参数、文献编号、字段名、失败样本）
2. 这段有没有取舍或限制？（为什么不用 B；在什么条件下不成立）
3. 删掉这段，论证会不会断？（不会断就删或并）

缺什么补什么。没有来源的数据写占位符，不编。

### 复跑与停止

最多三轮。三轮后仍未过线，列出未达标项交给作者，不要为了分数继续硬改，更不要删掉限制、伪造数据或把结论改软。

## 2. 段落展开的七种模型

### A. 数据切入

> 在【范围】内，【指标】为【值】，其中【比例】集中在【维度】。这个分布与【预期/文献】不一致，可能有两类原因：【原因 1】与【原因 2】。

适合：绪论背景、实验设置、问题提出。要求数字真实、口径清楚。

### B. 方案对比

> 【方案 A】在【条件】下【优点】，但【代价】；【方案 B】相反。本文取【选择】，因为【约束】优先于【次要指标】。

适合：研究现状、技术选型。对比必须落在同一指标上。

### C. 因果链

> 【现象】由【机制】导致。若【条件】改变，【结果】随之变化。这也解释了【异常/反例】。

适合：原理分析、结果解释。不要写“因为……所以……”却没有机制。

### D. 取舍

> 保留【 A】，放弃【B】，代价是【C】，换来【D】。这个交换在【场景】成立，在【场景 2】不成立。

适合：设计章。每章至少两处。

### E. 限制

> 样本只覆盖【范围】，【未覆盖项】未纳入统计。当【条件】时，【指标】降到【值】。这部分需要【数据/方法】才能回答。

适合：实验章、结论。限制要具体到条件与数值。

### F. 失败分析

> 在【样本类型】上方法失效，表现为【现象】。检查后发现【原因】。现有规则无法区分【X】与【Y】，这是后续工作。

适合：测试章。没有失败分析的实验章通常不可信。

### G. 文献对话

> 文献【n】在【数据】上用【方法】得到【结果】。该结论依赖【条件】；本文在【不同条件】下复现，得到【差异】。

适合：综述、讨论。引用必须给方法、数据、结论，不只给“研究表明”。

## 3. 章节节奏设计

一章 1,200–1,800 字时，按下面的节奏排：

1. **开头 2–3 段**：先给问题或约束，再给本文做法。不要先写“本章主要……”。
2. **中段**：长论证段（200–300 字）与短判断段（60–100 字）交替。短段用来转折、下判断、指出限制。
3. **结尾**：给限制、失败或下一步，不用“综上所述”收束。
4. **每千字至少**：1 个数字密集段、1 处取舍、1 处限制。
5. **每 4–6 句**：插入 1 句 12–18 字的短句。
6. **每章至少**：1 个 60–90 字的短段。

不要机械执行成“每段固定三长一短”。节奏是分布，不是公式。

## 4. 句式锚点怎么用

- 每章选 3–5 条，不要 9 条全用。
- 连续两段不得用同一条锚点。
- 同一条锚点每次填入不同信息类型：一次填数据，一次填取舍，一次填限制。
- 锚点与内容冲突时，弃用锚点，不要为了句式塞信息。
- 锚点只保留结构，不保留范文的术语组合、数值、结论。

## 5. 保真原则

改写时允许：删空话、拆并句、换主语、调序、补限定、把评价换成事实。

改写时不允许：

- 新增没有来源的数据、文献、实验结果。
- 改变原有结论的方向或强度。
- 删掉限制与失败分析来让报告好看。
- 把“未验证”改成“已验证”。
- 把他人观点写成自己的实验结果。

需要新信息时，写 `【待补：实验数据/文献出处/参数值】`，在交付清单里列出。

## 6. 逐句检查表

改完一段，逐句过一遍：

- [ ] 这句话有没有一个具体名词、数字或动作？
- [ ] 有没有“显著、极大、有效、全面”却没有数据？
- [ ] 是不是以“此外/同时/因此/首先”开头？能否删掉？
- [ ] 主语是不是又是“本文/系统”？能否换成对象或数据？
- [ ] 这句话能否与前句合并，或拆成两句？
- [ ] 有没有三项整齐排比、破折号解释、对偶句？
- [ ] 这句话是不是在重复上一句的意思？

## 7. 常见反效果

| 做法 | 结果 |
| --- | --- |
| 把长句全拆成短句 | 变成另一种均匀节奏，且逻辑断裂 |
| 每段都加数字 | 数字堆砌，同样机械 |
| 用生僻同义词替换术语 | 术语漂移，读者以为换了对象 |
| 加“笔者认为”但不给判断 | 只增加人称，不增加观点 |
| 删掉所有连接词 | 句间关系不明，读不懂 |
| 为拉长段落加背景废话 | 段落变长，信息密度更低 |
| 为通过门禁删掉限制 | 论文可信度下降，答辩必被问 |
| 改结论去迎合分数 | 学术不端，且与摘要/实验不一致 |

## 8. 一段话的自检标准

把改后的段落单独拿出来，问自己：

1. 同专业同学能否复述你用了什么数据、做了什么取舍？
2. 能否指出这段在什么条件下不成立？
3. 连续读三遍，是否感觉句子长短有变化，而不是匀速？

三个都能做到，才算改完。
